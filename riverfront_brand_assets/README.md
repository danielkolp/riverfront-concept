# Riverfront Bed & Breakfast Brand Assets

This pack includes SVG assets matching the more polished green/gold rustic-luxury direction.

## Included
- `logos/riverfront-logo-horizontal.svg`
- `logos/riverfront-logo-horizontal-dark-bg.svg`
- `logos/riverfront-mark.svg`
- `logos/favicon.svg`
- `icons/` amenity/contact/booking icons
- `decor/` botanical and river divider assets
- `brand-tokens.json`

## Suggested brand direction
- Primary: deep forest green
- Accent: muted river gold
- Background: warm cream
- Type pairing: a classy serif for headings, clean sans-serif for body/UI
- Use real photography for hero/gallery. Do not fake room photos with AI for the live business site unless clearly treated as placeholders.
